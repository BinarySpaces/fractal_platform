Список основных команд `uv`, которые тебе понадобятся при работе с FastAPI проектом.

## 📦 Управление проектом

**Создать новый проект:**
```bash
uv init my-project --bare
```
Создаёт папку с проектом и файл `pyproject.toml`.

**Добавить зависимость:**
```bash
uv add fastapi
```
Устанавливает пакет и записывает его в `pyproject.toml`.

**Добавить зависимость для разработки (dev):**
```bash
uv add ruff --dev
```
Пакет будет записан в секцию `[dependency-groups.dev]`, не влияет на продакшен.

**Удалить зависимость:**
```bash
uv remove fastapi
```

**Установить все зависимости из `pyproject.toml`:**
```bash
uv sync
```
Создаёт виртуальное окружение и устанавливает все пакеты из `pyproject.toml` и `uv.lock`.

**Синхронизировать только продакшен-зависимости (без dev):**
```bash
uv sync --no-dev
```

## 🚀 Запуск и выполнение

**Запустить скрипт через виртуальное окружение:**
```bash
uv run python app/main.py
```
Или для FastAPI:
```bash
uv run uvicorn app.main:app --reload
```

**Запустить команду внутри виртуального окружения:**
```bash
uv run ruff format .
```

## 📋 Проверка и обновление

**Посмотреть дерево зависимостей:**
```bash
uv tree
```

**Обновить все зависимости до последних версий:**
```bash
uv sync --upgrade
```

**Обновить конкретный пакет:**
```bash
uv add fastapi@latest
```

## 🧹 Очистка

**Удалить виртуальное окружение (если нужно начать заново):**
```bash
uv venv --clear
```

**Посмотреть, где находится виртуальное окружение:**
```bash
uv venv --path
```

## 💡 Полезные команды

**Инициализировать виртуальное окружение вручную (если не создалось автоматически):**
```bash
uv venv
```

**Активировать виртуальное окружение (созданное uv):**
```bash
source .venv/bin/activate   # Linux/Mac
.venv\Scripts\activate      # Windows (Git Bash)
```

**Добавить пакет с указанием версии:**
```bash
uv add "fastapi>=0.100.0,<0.200.0"
```

---

Остальное можно найти в `uv --help`
